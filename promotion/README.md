## 发布节奏建议

1. **先掘金**：长文沉淀技术细节，是三个平台里唯一能承载"八个坑"完整叙述的地方。掘金对 GitHub 外链有流量。
2. **再 V2EX**：节点选「创造」或「分享」。V2EX 开发者密度高，容易带来高质量讨论和 Star。
3. **最后 X**：主推帖 + 两条技术 thread，附视频。

## 硬性约束

- **不刷 Star、不自点。** 比赛规则允许取消资格。
- 不要在任何文案里暗示"麦当劳官方"或"官方合作"——本项目是参赛作品，非官方产品。
- 仓库不含真实 Token、密钥或个人信息，文案中也不要出现账号、门店地址以外的个人信息。
- 券后价、优惠金额等数字如需引用，**以 `calculate-price` 返回为准**；商品型券的直减金额未知，不要写"省 ¥X"。
